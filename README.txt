Habibi Party - static redesign (Bootstrap 5.3.8 + Anime.js 4.4.1)

Open index.html in a browser. Pages: index.html, shop.html.
Brand logos, mascots, fonts, Bootstrap, icons and Anime.js are bundled in /assets.
Product, pack, banner and setup photos load from https://habibi-party.vercel.app/assets/img/.
To host them yourself, copy that folder to assets/img/ and replace the URL
in assets/js/data.js (IMG constant) and index.html.
